# Datos originales

El archivo horario `hour.csv` se obtiene del [UCI Machine Learning Repository — Bike Sharing Dataset](https://archive.ics.uci.edu/dataset/275/bike-sharing-dataset). UCI indica licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); atribuye el dataset a Hadi Fanaee-T (2013), DOI: https://doi.org/10.24432/C5W894. Ejecuta `python scripts/download_data.py` para descargarlo. El proyecto guarda una copia local en esta carpeta, que está excluida de Git.

Antes de redistribuir los datos originales, revisa las condiciones de uso publicadas por UCI.
